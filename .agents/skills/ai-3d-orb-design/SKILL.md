# AI 3D Orb & Voice Assistant Visualizer Skill

This skill provides specialized guidelines for designing interactive, procedural 3D AI Orbs, voice assistant visualizers, and energy cores inspired by popular libraries (`react-ai-orb`, `orb-ui`, `jarvis-ai-web-animation`, Web Audio API visualizers).

## 1. 3D Orb Architectural Layers
- **Core Energy Stone / Nucleus**: Central emissive mesh (Octahedron / Icosahedron) emitting intense core light (`pointLight`) and high-frequency pulse frequencies.
- **Inner Liquid / Plasma Core**: Procedural 3D noise sphere simulating plasma currents, swirling galaxy nebulae, or fluid dynamics.
- **Holographic Matrix / Geometry Shell**: 4D Tesseract hypercubes, wireframe dodecahedrons, or intersecting laser rings that rotate and project data node vertices.
- **Outer Translucent Glass Shell**: Physical glass or fresnel refraction layer (`MeshPhysicalMaterial`) providing depth, specular highlights, and edge glows.
- **Atmospheric Particle Field**: Orbital starlight particles or energy dust drifting around the core along helical vector paths.

## 2. Activity State Feedback
- **`idle`**: Calming, low-frequency breathing pulse, subtle ambient rotation.
- **`listening`**: High-sensitivity ripple reactions, subtle scale expansion towards camera.
- **`thinking`**: Rapid multi-axis rotation, heightened noise frequency, electric arc sparks on shell edges.
- **`speaking`**: Powerful amplitude pulsing, dynamic shockwave wave rings radiating outward in sync with voice frequency data.
