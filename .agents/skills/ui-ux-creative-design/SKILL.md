# UI/UX Creative Design & Aesthetic Systems Skill

This skill provides comprehensive standards for building visually stunning, futuristic, and premium user interfaces (UI/UX) with glassmorphism, dynamic animations, and state-of-the-art color systems.

## 1. Design Aesthetics & Core Principles
- **First Impression Impact**: Avoid generic, plain colors or browser defaults. Use curated, harmonious color palettes (Tailored HSL/RGB, sleek dark modes, sci-fi metallic gradients).
- **Typography Excellence**: Use modern Google Fonts (e.g., *Outfit*, *Inter*, *Space Grotesk*, *Fira Code*) with crisp letter-spacing and hierarchy.
- **Glassmorphism & Depth**: Combine translucent background panels (`backdrop-filter: blur(...)`), subtle border glows (`box-shadow: 0 0 20px rgba(...)`), and multi-layered depth.
- **Micro-Animations & Feedback**: Implement continuous subtle micro-animations (pulse, float, sheen, hover elevation) to create a living, dynamic interface.

## 2. HUD & AI Assistant Interface Guidelines
- **Status States**: Standardize dynamic visual feedback across AI activity states (`idle`, `listening`, `thinking`, `speaking`, `executing`).
- **Interactive Drag & Tilt**: Provide smooth spring physics (lerp interpolation) when users drag or tilt 3D HUD elements.
- **Minimalist Controls**: Keep floating taskbars, side panels, and action docks non-intrusive with auto-hide or sleek semi-transparent backdrops.
